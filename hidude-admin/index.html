Nerede Dur Demelisiniz? & Hızlı Kontrol

HiDude'un tek ücretli sınır noktası Firebase Spark günlük 20.000 yazma / 20.000 silme kotasıdır. Kullanıcı sayısını durdurmak isterseniz:

  • %50–%80 (Sarı): Kullanıcı artışını izleyin, yeni tanıtımları yavaşlatın.
  • %80+ (Kırmızı): Firebase Console → Authentication → Settings → User actions üzerinden geçici olarak yeni üye kaydını kapatabilir veya Blaze + bütçe uyarısı tanımlayabilirsiniz.
  • P2P & Çevrimdışı AI: Arama sesi/videosu ile yapay zeka çevirisi telefonlarda çalıştığı için ek sunucu maliyeti üretmez.
